Reference API

The following classes are exposed to the user. The HTTP-specific classes live in the sub-package of the HTTP client that you use, httpx_limiter.httpx or httpx_limiter.httpx2, and each requires the matching extra.

  • Rate
  • Number
  • AbstractAsyncLimiter
  • AsyncRateLimitedTransport
  • AbstractRateLimiterRepository
  • AsyncMultiRateLimitedTransport
  • HTTPXAsyncHTTPTransportKeywordArguments

  • AbstractRateLimiterRepository (HTTPX2)
  • AsyncMultiRateLimitedTransport (HTTPX2)
  • HTTPXAsyncHTTPTransportKeywordArguments (HTTPX2)
  • AiolimiterAsyncLimiter
  • PyrateAsyncLimiter

Provide top level symbols.

This package does not import any HTTP client. Select an integration explicitly via httpx_limiter.httpx or httpx_limiter.httpx2.

AbstractAsyncLimiter ¶

Bases: ABC

Define an abstract base class for asynchronous rate limiters.

This interface dictates that all asynchronous rate limiters shall implement the context manager protocol.

HTTPX¶

httpx_limiter.httpx ¶

Provide the HTTPX integration.

Importing this package requires the httpx extra, for example pip install "httpx-limiter[httpx]".

AsyncRateLimitedTransport ¶

Bases: AsyncBaseTransport

Define the asynchronous rate-limited transport.

This transport consists of a composed transport for handling requests and an implementation of a leaky bucket algorithm in order to rate-limit the number of requests.

__aenter__() -> Self async ¶

Enter the transport and its underlying transport.

Entering this wrapper, for example through the client's context, also enters the composed transport, so that it can set up its resources.

__aexit__(exc_type: type[BaseException] | None = None, exc_value: BaseException | None = None, traceback: TracebackType | None = None) -> None async ¶

Exit the transport and its underlying transport.

Exiting this wrapper, for example through the client's context, exits the composed transport with the same exception details, which lets it clean up its resources.

__init__(*, limiter: AbstractAsyncLimiter, transport: httpx.AsyncBaseTransport, **kwargs: dict[str, object]) -> None ¶

aclose() -> None async ¶

Close the transport and its underlying transport.

Closing this wrapper also closes the composed transport, which is why sharing an inner transport between wrappers shares its lifetime.

AbstractRateLimiterRepository ¶

Bases: RateLimiterRepository[Request]

Define the abstract repository for rate limiters of HTTPX requests.

This abstract base class provides a framework for managing rate limiters based on HTTPX requests. It maintains a cache of rate limiters and provides methods to retrieve request-specific identifiers and limiters.

Subclasses must implement methods to determine how requests are identified and what rate limits should be applied to them.

Methods:

Name Description
get_identifier

Return a request-specific identifier.
create

Return a request-specific rate limiter.
get

Return a request-specific rate limiter.
